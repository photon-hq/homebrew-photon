# Photon Homebrew Tap

Official Homebrew tap for [Photon](https://github.com/photon-hq) open-source tools.

## Usage

```bash
brew tap photon-hq/photon
```

## Available Formulas

| Formula | Description | Install |
|---------|-------------|---------|
| `jamf-package-updater` | Safely update Jamf Pro packages in place without breaking policies | `brew install photon-hq/photon/jamf-package-updater` |

## Install

```bash
# Add the tap (one-time)
brew tap photon-hq/photon

# Install a formula
brew install <repo-name>

# Update
brew upgrade  <repo-name>
```
